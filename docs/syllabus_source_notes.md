# Syllabus grounding sources

The bot uses source portals to inform topic taxonomy and exam-style framing; it does not copy copyrighted guide-book wording or claim that generated practice questions are official prior-paper items.

| Source | What it supports | URL |
|---|---|---|
| NCERT Textbooks PDF portal | National subject concepts and class-level textbook taxonomy across Classes I–XII. | https://ncert.nic.in/textbook.php |
| Board of Secondary Education, Rajasthan — Download Books | Rajasthan board textbook availability and RBSE-aligned topic grounding. | https://rajeduboard.rajasthan.gov.in/books/index.htm |
| Kerala Public Service Commission — Previous Question Paper | Evidence that state commissions publish official prior-paper catalogs; suitable for pattern reference, not unlicensed bulk reproduction. | https://www.keralapsc.gov.in/previous-question-papers |
| Rajasthan Public Service Commission — Previous Question Papers | Rajasthan state-exam pattern reference and official paper catalog. | https://rpsc.rajasthan.gov.in/previousquestionpapers.aspx |
| Union Public Service Commission — Previous Question Papers | National competitive-exam pattern reference and official paper catalog. | https://www.upsc.gov.in/examinations/previous-question-papers |

## Content policy

Generated items are labelled as syllabus-grounded competitive-exam practice. The system must not state or imply that a generated item was copied from a prior paper, published by a board, or guaranteed to occur in an examination. Current-affairs questions remain restricted to configured source-backed facts.
